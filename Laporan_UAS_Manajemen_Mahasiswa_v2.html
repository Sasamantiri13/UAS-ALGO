BAB I: PENDAHULUAN

1.1 Latar Belakang

Pengelolaan data akademik mahasiswa merupakan pilar utama sistem administrasi pada institusi pendidikan tinggi. Seiring meningkatnya jumlah data, kebutuhan akan sistem penyimpanan yang dinamis dan algoritma pengurutan serta pencarian data yang efisien menjadi sangat krusial. Oleh karena itu, proyek akhir ini menghadirkan aplikasi Manajemen Data Mahasiswa.

Aplikasi ini dikembangkan menggunakan bahasa pemrograman Python untuk membuktikan penguasaan pemrograman berorientasi objek (OOP), alokasi memori berantai menggunakan penunjuk referensi pointer melalui struktur data Doubly Linked List, validasi pola data menggunakan Regular Expression (Regex), serta ketahanan program terhadap kesalahan input melalui Exception Handling. Aplikasi ini dilengkapi dengan dua variasi antarmuka, yaitu berbasis Command Line Interface (CLI) dan Graphical User Interface (GUI) modern untuk memberikan pengalaman interaksi pengguna yang maksimal.

1.2 Tujuan Proyek

Tujuan dari perancangan dan penyempurnaan proyek perangkat lunak ini adalah:

  1. Menerapkan paradigma pemrograman berbasis objek (OOP) secara terstruktur meliputi Enkapsulasi, Pewarisan, dan Polimorfisme.
  2. Mensimulasikan konsep alokasi memori berantai menggunakan pointer dengan merancang Doubly Linked List dinamis tanpa pustaka tambahan.
  3. Mengimplementasikan dan membandingkan performa 3 jenis algoritma pengurutan data: Bubble Sort, Insertion Sort, dan Merge Sort.
  4. Mengimplementasikan dan membandingkan efisiensi 3 jenis metode pencarian data: Linear Search pada list, Binary Search pada list terurut, dan Sequential Search yang menyusuri node Linked List.
  5. Mencegah kesalahan masukan data (data integrity) dengan memasang validasi Regular Expression (Regex) yang terperangkap dalam blok Try-Catch & Exception.
  6. Menganalisis kompleksitas waktu (Big O Notation) pada fitur utama sistem sebagai tinjauan efisiensi algoritma.

1.3 Framework dan Arsitektur Aplikasi

Aplikasi dikembangkan menggunakan bahasa pemrograman Python 3 dengan memanfaatkan kombinasi pustaka bawaan dan pihak ketiga demi mencapai pemisahan yang bersih antara penyimpanan data, logika bisnis, dan presentasi visual:

  • Tkinter: Framework GUI bawaan Python yang digunakan untuk membangun antarmuka grafis standar pada file gui.py.
  • CustomTkinter: Framework eksternal modern yang membungkus Tkinter untuk menghasilkan antarmuka grafis modern bertema gelap/terang (dark/light mode), sudut membulat (rounded corners), dan transisi dinamis pada file modern_gui.py.
  • Matplotlib & FigureCanvasTkAgg: Pustaka plotting yang digunakan untuk merender visualisasi grafik batang sebaran mahasiswa per jurusan dan grafik histogram sebaran nilai IPK secara interaktif di dalam canvas GUI CustomTkinter.
  • Arsitektur MVC (Model-View-Controller): Logika program dibagi secara modular menjadi Model (kelas mahasiswa dan linked list di models.py dan data_structures.py), Controller (mesin pencarian, pengurutan, validasi regex, dan file I/O di manager.py, validator.py, file_manager.py), serta View (antarmuka teks dan GUI di main.py, gui.py, modern_gui.py).

BAB III: STRUKTUR DATA DAN ANALISIS ALGORITMA KUNCI

3.1 Model Pemrograman Berorientasi Objek (OOP)

Implementasi OOP pada proyek ini ditunjukkan dengan membagi entitas menjadi kelas induk dan kelas anak. Enkapsulasi diterapkan dengan menjaga variabel data mahasiswa tetap privat (diawali double underscore __) dan hanya dapat diakses melalui property decorator. Polimorfisme digunakan pada fungsi tampilkanInfo() yang di-override oleh kelas anak untuk menghasilkan representasi info status yang berbeda. 

# Penerapan OOP pada models.py
class Person:
    def __init__(self, nama):
        self.__nama = nama # Atribut Privat

    @property
    def nama(self): # Getter
        return self.__nama

class Mahasiswa(Person):
    def __init__(self, nim, nama, jurusan, semester, ipk):
        super().__init__(nama) # Pewarisan (Inheritance)
        self.__nim = nim
        self.__jurusan = jurusan
        self.__semester = semester
        self.__ipk = ipk

class MahasiswaAktif(Mahasiswa):
    def tampilkanInfo(self):
        # Polimorfisme: Meng-override metode induk
        print("=== Data Mahasiswa Aktif ===")
        super().tampilkanInfo()
        print(f"Status: Aktif")

3.2 Representasi Pointer: Struktur Data Doubly Linked List

Representasi pointer dinamis dalam memori disimulasikan menggunakan kelas Node dan DoublyLinkedList secara manual. Setiap node menyimpan referensi penunjuk next ke node berikutnya dan prev ke node sebelumnya. 

# Representasi Pointer Node pada data_structures.py
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None # Pointer ke node setelahnya
        self.prev = None # Pointer ke node sebelumnya

class DoublyLinkedList:
    def __init__(self):
        self.head = None
        self.tail = None
        self.size = 0

    def append(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = self.tail = new_node
        else:
            new_node.prev = self.tail
            self.tail.next = new_node # Menghubungkan penunjuk pointer next
            self.tail = new_node
        self.size += 1

3.3 Pencarian Berurutan (Sequential Search) Melalui Pointer Traversal

Algoritma pencarian ketiga, Sequential Search, diimplementasikan dengan menelusuri penunjuk referensi pointer current.next dari node-ke-node langsung pada struktur Doubly Linked List tanpa mengonversinya ke bentuk list bawaan. 

    @staticmethod
    def sequentialSearch(linked_list, value, key="nim"):
        iterations = 0
        current = linked_list.head # Inisialisasi awal pada head pointer
        index = 0
        while current:
            iterations += 1
            item = current.data
            if str(getattr(item, key)).lower() == str(value).lower():
                return index, iterations
            current = current.next # Traversal pointer ke node selanjutnya
            index += 1
        return -1, iterations

3.4 Algoritma Pengurutan Baru (Insertion Sort)

Metode sorting tambahan Insertion Sort ditambahkan pada SortEngine dengan menghitung perbandingan, pergeseran (swaps), dan durasi pencatatan waktu eksekusi riil: 

    @staticmethod
    def insertionSort(data, key="nim"):
        n = len(data)
        comparisons = 0
        swaps = 0
        start_time = time.time()
        for i in range(1, n):
            key_item = data[i]
            j = i - 1
            while j >= 0:
                comparisons += 1
                val_j = getattr(data[j], key)
                val_key = getattr(key_item, key)
                if val_j > val_key:
                    data[j + 1] = data[j]
                    swaps += 1 # Pergeseran data
                    j -= 1
                else:
                    break
            data[j + 1] = key_item
        return comparisons, swaps, time.time() - start_time

BAB IV: PANDUAN OPERASIONAL PENGGUNAAN PROGRAM

4.1 Kredensial Autentikasi Admin

Demi keamanan data akademik mahasiswa, semua antarmuka program dilengkapi dengan sistem autentikasi login administrator. Kredensial masuk default yang dikonfigurasi adalah:

  • Username Default: admin
  • Password Default: admin123

Kredensial ini disimpan dalam bentuk hash aman menggunakan algoritma SHA-256 pada file teks users.txt untuk mencegah pencurian kata sandi secara langsung.

4.2 Panduan Versi Command Line Interface (CLI)

Untuk menjalankan aplikasi versi teks, eksekusi perintah python main.py di terminal. Masukkan kredensial admin untuk masuk ke menu utama. Menu utama menyajikan pilihan sebagai berikut:

  1. Tambah Data: Meminta input NIM, Nama, Jurusan, Semester, IPK, dan Status. Validasi Regex akan langsung memeriksa setiap field.
  2. Tampilkan Seluruh Data: Menampilkan data dalam format tabel dengan kolom NIM, Nama, Jurusan, Semester, IPK, dan Status.
  3. Edit Data (by NIM): Masukkan NIM target, edit data yang diinginkan, lalu simpan perubahan.
  4. Hapus Data (by NIM): Memasukkan NIM mahasiswa dan memberikan konfirmasi penghapusan (y/n).
  5. Cari Mahasiswa: Menyediakan pencarian NIM (Binary Search), Nama (Linear Search), atau NIM/Nama (Sequential Search LinkedList).
  6. Urutkan Data: Mengurutkan NIM (Bubble/Insertion Sort), Nama (Merge Sort), atau IPK (Merge Sort).
  7. Simpan Data ke CSV: Melakukan sinkronisasi data dari Linked List ke file mahasiswa.csv.
  8. Load Data dari CSV: Memuat ulang database dari file CSV ke struktur Linked List.
  9. Bantuan & Statistik Kompleksitas: Menampilkan kamus kompleksitas algoritma (Big O Notation) untuk edukasi UAS.
  10. Keluar: Menutup aplikasi secara aman.

4.3 Panduan GUI Standar (gui.py)

Untuk menjalankan antarmuka visual standar, eksekusi perintah python gui.py di terminal.

  • Form Input (Kiri): Isi kolom data mahasiswa (NIM, Nama, Jurusan, Semester, IPK) dan pilih status pada combobox. Tekan tombol Tambah untuk memasukkan, Update untuk memperbarui baris terpilih, atau Hapus untuk menghapus baris terpilih.
  • Bilah Pencarian (Search Bar - Kanan Atas): Masukkan kata kunci pencarian, pilih metode pencarian (NIM Binary, Nama Linear, atau DLL Sequential) melalui radio button, lalu klik tombol Cari. Klik Reset untuk mengembalikan seluruh tabel.
  • Bilah Dropdown Sort (Kanan Atas): Pilih algoritma pengurutan (Bubble Sort, Insertion Sort, atau Merge Sort) dari dropdown, lalu klik salah satu header kolom tabel (NIM, Nama, Jurusan, dsb.) untuk mengurutkan data berdasarkan kolom tersebut.

4.4 Panduan GUI Modern (modern_gui.py)

Untuk menjalankan antarmuka visual modern, eksekusi perintah python modern_gui.py di terminal. GUI Modern ini dibangun menggunakan framework CustomTkinter dan dilengkapi visualisasi statistik:

  • Sidebar Menu (Kiri): Menyediakan tombol perpindahan halaman antarmuka (Dashboard & Statistik) serta dropdown pemilih tema tampilan (Dark & Light Mode).
  • Halaman Dashboard: Berisi form pengelolaan data mahasiswa modern (input dengan placeholder), tombol manipulasi dengan gradasi warna yang interaktif, tabel data gelap, dropdown pencarian dengan cache invalidation otomatis, dan opsi sorting dropdown.
  • Halaman Statistik: Menampilkan grafik visual Matplotlib secara dinamis berupa Bar Chart sebaran mahasiswa per Jurusan dan Histogram distribusi nilai IPK mahasiswa.
